# Python Functions


A function is a reusable block of code that performs a specific task. Define a function using `def` and call it using its name.

def greet(name):
    print("Hello", name)


greet("Payal")

A function can return a value using return.

def add(a, b):
    return a + b


result = add(10, 20)
print(result)

# Keep in mind
def is used to define a function.
Parameters receive values passed to a function.
return sends a value back.
Functions help avoid repeating code.
