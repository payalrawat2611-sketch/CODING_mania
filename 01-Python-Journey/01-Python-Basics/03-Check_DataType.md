# Python Data Types

Python determines the data type automatically.

| Type | Example |
|---|---|
| `int` | `10` |
| `float` | `10.5` |
| `complex` | `2 + 3j` |
| `str` | `"Python"` |
| `bool` | `True` / `False` |
| `list` | `[1, 2, 3]` |
| `tuple` | `(1, 2, 3)` |
| `set` | `{1, 2, 3}` |
| `dict` | `{"name": "Payal"}` |
| `None` | `None` |

# Keep in mind

x = 10
print(type(x))

type() → tells the type of a value.

list → mutable
tuple → immutable
set → unique values
dict → key-value pairs
