## Inheritance allows one class to acquire the properties and methods of another class.

Basic Example
class Animal:
    def eat(self):
        print("Eating")




class Dog(Animal):
    def bark(self):
        print("Barking")




dog = Dog()


dog.eat()
dog.bark()

Output:

Eating
Barking

Here, Dog inherits from Animal.

Animal → Parent class
Dog → Child class
Constructor Inheritance

A child class can also have its own constructor.

class Animal:
    def __init__(self, name):
        self.name = name




class Dog(Animal):
    def bark(self):
        print(self.name, "is barking")




dog = Dog("Bruno")
dog.bark()

Output:

Bruno is barking
super()

super() is used to call methods or the constructor of the parent class.

class Animal:
    def __init__(self, name):
        self.name = name




class Dog(Animal):
    def __init__(self, name, age):
        super().__init__(name)
        self.age = age




dog = Dog("Bruno", 3)


print(dog.name)
print(dog.age)
🧠 Remember
Inheritance → Reuse properties and methods of another class.
Parent class → Class being inherited from.
Child class → Class that inherits.
super() → Accesses the parent class.
Inheritance promotes code reuse.
