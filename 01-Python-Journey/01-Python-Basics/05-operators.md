# Python Operators

# Arithmetic Operators

`+` Addition  
`-` Subtraction  
`*` Multiplication  
`/` Division  
`//` Floor Division  
`%` Modulus  
`**` Exponent

a = 10
b = 3

print(a + b)
print(a // b)
print(a % b)
print(a ** b)

Logical Operators
and → both conditions must be True
or → at least one condition must be True
not → reverses the result

#Keep in mind
= is assignment, while == is comparison.
/ returns a decimal value.
// gives floor division.
% gives the remainder.
** is used for power.
