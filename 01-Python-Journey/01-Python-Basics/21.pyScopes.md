Scope determines where a variable can be accessed in a program.

1. Local Scope

A variable created inside a function is local to that function.

def greet():
    name = "Payal"
    print(name)


greet()

name cannot normally be accessed outside greet().

2. Global Scope

A variable created outside a function has global scope.

name = "Payal"


def greet():
    print(name)


greet()

A function can read a global variable.

3. global Keyword

Use global when you want to modify a global variable inside a function.

count = 0


def update():
    global count
    count += 1


update()


print(count)

Output:

1
4. nonlocal Keyword

nonlocal is used inside a nested function to modify a variable from the outer function.

def outer():
    count = 0


    def inner():
        nonlocal count
        count += 1


    inner()
    print(count)


outer()

Output:

1
🧠 Remember
Local → variable inside a function.
Global → variable outside functions.
global → modify a global variable inside a function.
nonlocal → modify a variable from an enclosing function.
Python generally searches variables in Local → Enclosing → Global → Built-in (LEGB) order.
