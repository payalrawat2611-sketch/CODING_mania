# 📝 Python Comments

## What are comments?

Comments are notes written in Python code that are ignored by the Python interpreter.

They are used to explain code, leave reminders, and make programs easier to understand.

---

## 1. Single-line Comments

Use `#` to write a single-line comment.

```python
# This is a comment
print("Hello Python")
```

### Quick Revision

```text
# → Single-line comment
```

---

## 2. Multi-line Comments

Python does not have a dedicated multi-line comment syntax.

Triple quotes `""" ... """` create a **multi-line string**. When they are not assigned to a variable, they can commonly be used like a multi-line comment.

```python
"""
This is a multi-line string.
It can be used like a multi-line comment.
"""

print("Hello Python")
```

### Quick Revision

```text
""" ... """ → Multi-line string
               commonly used like a multi-line comment
```

> 💡 **Important:** `""" ... """` is technically a string, not a comment.

---

## 🧠 My Notes

- Comments are not executed as Python statements.
- Use comments to explain important parts of code.
- Avoid unnecessary comments.
- Keep comments short and meaningful.
- Triple quotes create strings and are also used for docstrings.
