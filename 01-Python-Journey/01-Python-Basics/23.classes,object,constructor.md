# 🏗️ Python Classes, Objects & Constructors

## What is a Class?

A **class** is a blueprint for creating objects.

A class can contain **attributes** (data) and **methods** (functions).

```python
class Student:
    def stu
dy(self):
        print("Student is studying")
```

## What is an Object?

An **object** is an instance of a class.

```python
student1 = Student()

student1.study()
```

Output:

```text
Student is studying
```

## Attributes

Attributes store information about an object.

```python
class Student:
    def set_details(self, name, age):
        self.name = name
        self.age = age

student1 = Student()

student1.set_details("Payal", 20)

print(student1.name)
print(student1.age)
```

## `self`

`self` refers to the **current object**.

```python
class Student:
    def greet(self):
        print("Hello")

student1 = Student()
student1.greet()
```

Python automatically passes `student1` as `self`.

## Constructor `__init__()`

A **constructor** is a special method that runs automatically when an object is created.

In Python, the constructor is usually `__init__()`.

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

student1 = Student("Payal", 20)

print(student1.name)
print(student1.age)
```

Output:

```text
Payal
20
```

The constructor initializes the object's attributes when the object is created.

## 🧠 Remember

* **Class** → Blueprint for objects.
* **Object** → Instance of a class.
* **Attribute** → Data belonging to an object.
* **Method** → Function inside a class.
* `self` → Refers to the current object.
* `__init__()` → Constructor that runs when an object is created.
