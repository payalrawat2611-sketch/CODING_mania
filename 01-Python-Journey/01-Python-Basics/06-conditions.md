# Python Conditions

Conditions are used to make decisions in a program.

#if

age = 20

if age >= 18:
    print("Adult")


# if-else

age = 16

if age >= 18:
    print("Adult")
else:
    print("Minor")


# if-elif-else :

marks = 75


if marks >= 90:
    print("A")
elif marks >= 60:
    print("B")
else:
    print("C")


#keep in mind

Use : after if, elif, and else.
Python uses indentation to define blocks.
Conditions return True or False.
